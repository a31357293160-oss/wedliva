# WedLiva components

- `InvitationPage.tsx` — the first luxury template.
- `Reveal.tsx` — scroll-in animation wrapper.
- `ScratchReveal.tsx` — touch/mouse scratch-to-reveal interaction.
- `Countdown.tsx` — live wedding countdown.
- `MusicButton.tsx` — background music control.

For production, move invitation data out of `lib/invitation.ts` and load it from Supabase using the URL slug.
